# ਚਿੱਤਰ-ਮਾਲਾ · Gallery images

Heritage images connected with Sikh tradition: manuscripts and pothis, Nishans and hukamnamas,
Janamsakhi paintings, historic paintings and frescoes, coins, and historic documents and places.

| `nishan/` | ਨੀਸਾਣ ਤੇ ਹੁਕਮਨਾਮੇ | Nishans & hukamnamas |

| `sikke/` | ਸਿੱਕੇ | Coins |

## Rules for this folder
- **Only public-domain or Creative Commons images**, each recorded in `site/data/gallery.json` with its licence,
  author and source page. `tools/fetch_gallery.py` enforces this.
- **These images are not covered by this repository's CC BY-SA licence.** Each keeps its own licence; check
  `gallery.json` before reusing one.
- Name files `<id>.<ext>`, using the same id as in `gallery.json`.
- Dates and attributions are given as the source states them.

Paintings of the Guru Sahiban are artists' imaginings, preserved here as historic art. Please view and use them with respect.
